## 0.1.0 — first release

- Transmitters are placed with all sides disconnected, except the side facing the block you clicked.
- Placing against an existing transmitter also opens that transmitter's facing side (symmetric open).
- GregTech-style 3x3 sided guide while holding the Configurator or a transmitter item; icons follow each side's live connection state (connected / blocked / push / pull).
- Grid cells can be used to choose the placement side (cell-select placement), with a server-side guard against double placement.
- Per-type config toggles (energy, fluid, chemical, heat, item), clicked-side and counterpart options, and a mode for non-player placements.
- No dedicated items; the Mekanism Configurator remains the only tool.
